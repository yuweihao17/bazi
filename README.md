# 四柱八字及大运计算器

一个支持公历与农历输入的四柱八字计算工具，能够自动计算大运信息并提供流年查询功能。

## 功能特点

### 基础功能
- ✅ 支持公历和农历日期输入
- ✅ 自动计算四柱八字（年柱、月柱、日柱、时柱）
- ✅ 支持性别输入，影响大运计算
- ✅ 农历闰月自动识别

### 大运计算
- ✅ 遵循传统命理学规则计算起运时间
- ✅ 支持阳年男性/阴年女性顺行，阴年男性/阳年女性逆行
- ✅ 基于二十四节气精确计算起运年龄
- ✅ 三天计一岁的传统算法
- ✅ 显示八部大运的干支、年份和对应岁数

### 流年查询
- ✅ 交互式查询任意大运的十年流年详情
- ✅ 显示每年的流年干支、公历年份和对应年龄
- ✅ 支持退出和重复查询

### 干支关系分析（新增）
- ✅ 全面分析八字中天干地支的作用关系
- ✅ 天干关系：相合（甲己合化土等）和相克（甲戊相克等）
- ✅ 地支关系：六合、三合、三会、暗合、拱合、相刑、六冲、六破、六害
- ✅ 显示具体位置信息（年干、月支等）便于理解

## 重要修正说明

### 传统命理学0岁起算

在最新版本中，我们修正了大运年份计算的重要问题：

**问题描述：**
- 对于立春前出生的八字，年柱使用前一年的干支
- 但大运年份计算应该遵循传统命理学的0岁起算规则

**修正逻辑：**
1. **传统0岁起算**：出生年为0岁，而非现代的1岁
2. **大运年份计算**：出生年 + 起运年龄 = 大运开始年份
3. **实际年龄对应**：起运年龄显示不变，但实际走大运时为起运年龄+1岁

**修正案例：**
```
出生信息：2004年1月30日6时（男性）
年柱：癸未（立春前，用2003年干支）
起运：8岁0个月0天0个时辰

修正前：2013年开始走甲子大运
修正后：2012年开始走甲子大运 ✅

解释：
- 2004年出生 = 0岁（传统算法）
- 8岁起运 = 2004年 + 8年 = 2012年
- 2012年壬辰年，此人9岁，开始走甲子大运
```

## 使用示例

### 基础使用流程：
1. 运行程序：`python 2.py`
2. 输入性别：男/女
3. 选择历法：g(公历) 或 n(农历)
4. 输入出生日期和时间
5. 查看八字和大运结果

### 流年查询流程：
6. 在大运结果显示后，程序会进入流年查询模式
7. 输入要查询的大运干支（如：甲子、癸亥等）
8. 查看该大运十年的流年详情
9. 输入 'q' 或 'quit' 退出查询

## 技术特点

1. **精确计算**：严格按照传统命理学规则计算
2. **智能节气**：自动计算二十四节气，支持跨年查找
3. **用户友好**：清晰的界面布局和错误提示
4. **交互式设计**：支持连续查询多个大运
5. **兼容性强**：兼容不同版本的lunar-python库
