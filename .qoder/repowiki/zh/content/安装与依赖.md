## 项目概述

本项目是一个四柱八字计算器，支持公历和农历输入，能够自动计算对应的四柱八字。项目依赖于`lunar-python`库来实现农历转公历、节气计算及八字生成等核心功能。

## Python版本要求

本项目建议使用 **Python 3.7 或更高版本**。代码中使用了类型注解（如 `-> bool`、`Optional[int]` 等），这些特性在 Python 3.5+ 中被引入，并在后续版本中得到更好支持。为确保兼容性和稳定性，推荐使用 Python 3.7+。

用户可通过以下命令检查本地 Python 版本：

```bash
python --version
# 或
python3 --version
```

若系统中安装了多个 Python 版本，建议使用 `python3` 命令以明确调用 Python 3 解释器。

## 核心依赖库lunar-python

`lunar-python` 是本项目的核心依赖库，其作用不可替代，原因如下：

- **农历转公历**：提供精确的农历与公历相互转换功能。
- **节气计算**：内置二十四节气的计算逻辑。
- **八字生成**：根据出生时间自动生成年柱、月柱、日柱、时柱。

该库封装了复杂的天文历法算法，使开发者无需自行实现底层计算逻辑。

## 安装步骤

### 1. 安装lunar-python

使用 `pip` 包管理器安装核心依赖库：

```bash
pip install lunar-python
```

对于某些系统（如 Windows 使用 PowerShell）或存在多版本 Python 的环境，建议使用以下命令以确保正确安装：

```bash
python -m pip install lunar-python
```

此命令明确指定使用当前 Python 环境的 pip 模块进行安装，避免因路径问题导致安装失败。

## 环境准备完整流程

为确保项目运行环境的纯净与可复现，推荐按照以下完整流程进行环境准备：

### 步骤 1：创建虚拟环境

```bash

python -m venv venv

# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate
```

### 步骤 2：安装依赖

```bash
pip install lunar-python
```

### 步骤 3：运行脚本

将主程序保存为 `bazi_calculator.py`，然后运行：

```bash
python bazi_calculator.py
```

该流程确保了项目依赖与其他 Python 项目的隔离，避免版本冲突。

## 常见安装问题及解决方案

### 1. 网络问题导致下载失败

**问题表现**：`pip install` 超时或连接错误。

**解决方案**：使用国内镜像源加速下载：

```bash
pip install lunar-python -i https://pypi.tuna.tsinghua.edu.cn/simple/
```

常用镜像源：
- 清华大学：`https://pypi.tuna.tsinghua.edu.cn/simple/`
- 阿里云：`https://mirrors.aliyun.com/pypi/simple/`

### 2. 权限错误

**问题表现**：`PermissionError` 或 `Access is denied`。

**解决方案**：
- **不推荐**：使用 `sudo pip install`（可能破坏系统环境）
- **推荐**：使用虚拟环境（如上所述）

### 3. 版本冲突

**问题表现**：`ERROR: Cannot install lunar-python==X and lunar-python==Y`。

**解决方案**：清理缓存并重新安装：

```bash
pip cache purge
pip install lunar-python
```

或在虚拟环境中重新创建环境。

## 验证安装

安装完成后，可通过运行主程序自动验证依赖完整性。程序启动时会调用 `ensure_lunar_python()` 函数检查 `lunar-python` 库是否可用：

```python
def ensure_lunar_python() -> bool:
    try:
        from lunar_python import Solar, Lunar
        return True
    except ImportError:
        print("未检测到依赖库 lunar-python。\n请先安装：pip install lunar-python")
        return False
```

如果库未安装，程序将提示用户执行安装命令，确保使用体验友好。

## 项目轻量级特性

本项目具有以下轻量级特性：
- **无需额外配置文件**：所有逻辑内置于单个脚本中，无需 `.json`、`.yaml` 等配置文件。
- **无需编译步骤**：纯 Python 脚本，直接运行即可。
- **依赖单一**：仅依赖 `lunar-python` 一个外部库，易于维护和部署。

这些特性使得项目易于分发和使用，适合快速计算和集成。
