## 简介
本指南旨在帮助新用户在5分钟内完成四柱八字计算器的首次运行。该程序支持公历与农历输入，自动计算并输出完整的八字信息，包括公历时间、农历时间、四柱（年柱、月柱、日柱、时柱）等详细内容。

## 运行步骤
要成功运行本程序，请按照以下三个简单步骤操作：

1. **打开终端**：启动命令行工具（如Windows的CMD或PowerShell，macOS/Linux的Terminal）。
2. **导航至项目目录**：使用`cd`命令进入包含`2.py`文件的目录。例如：
   ```
   cd C:\Users\20749\Desktop\新建文件夹 (2)
   ```
3. **执行脚本**：运行以下命令启动程序：
   ```
   python 2.py
   ```

确保系统已安装Python环境，并建议提前安装所需依赖库以避免运行中断。

## 交互流程
程序启动后将按以下流程与用户进行交互：

1. **显示欢迎信息**：程序首先输出标题和使用说明，提示用户如何输入数据。
2. **选择输入方式**：用户需选择输入历法类型：
   - 输入 `g` 表示使用**公历**
   - 输入 `n` 表示使用**农历**
3. **依次输入时间信息**：根据所选历法，程序将提示用户依次输入年、月、日、时四个参数。
4. **自动计算并输出结果**：系统验证输入有效性后，调用算法计算八字，并格式化输出最终结果。

整个过程设计简洁直观，用户只需按提示操作即可完成计算。

## 输入限制
为确保程序稳定运行，请注意以下输入范围限制：
- **年份**：必须为1至9999之间的整数
- **月份**：公历与农历均为1至12
- **日期**：
  - 公历日：1至31
  - 农历日：1至30
- **小时**：0至23（24小时制）

程序具备输入验证机制，若输入超出范围或非数字字符，将提示错误并要求重新输入。

## 功能说明
本程序所有功能均在主文件`2.py`中实现，无需额外配置或操作。核心功能包括：
